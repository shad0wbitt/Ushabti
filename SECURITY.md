# Security Policy

## Reporting a vulnerability

Email security reports to the maintainer. Do not open public issues for undisclosed vulnerabilities. We aim to acknowledge within 72 hours and patch within 30 days.

## Supported versions

Only the latest release on the `dev` branch is supported.

## Scope

In scope: path traversal in file tools, command injection in bash, secret leakage in logs/traces, auth bypass in harnessd, SSRF in web_fetch. Out of scope: social engineering, physical access.
